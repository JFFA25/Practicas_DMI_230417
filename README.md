## Descripción

Este repositorio contiene las prácticas desarrolladas durante la materia de **Desarrollo Móvil Integral**, correspondiente a la carrera de Ingeniería en Desarrollo y Gestión de Software.

El objetivo es aplicar los fundamentos del desarrollo de aplicaciones móviles multiplataforma utilizando **Flutter** y el lenguaje **Dart**, abarcando desde la construcción de interfaces (widgets), manejo de estado y navegación, hasta la integración con servicios externos y el empaquetado final de las apps.

Cada práctica incluye el código fuente, una breve descripción del objetivo de aprendizaje y, cuando aplica, capturas de pantalla o evidencias del funcionamiento de la aplicación.
